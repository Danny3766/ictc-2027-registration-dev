# 大會匯入狀態調整

決策見 [需求討論與決策紀錄](需求討論與決策紀錄.md)「2026-11-11 大會匯入狀態調整」。

## 部署

1. 執行 `supabase/migrations/202611110002_conference_import_status.sql`。首次初始化只設定 category 為 meeting、台灣日期為 2027-02-20 或 2027-02-21 的活動，不更新任何登記的匯入狀態；確認只有兩天特會被勾選。
2. 更新 `supabase/functions/staff/index.ts`。不需更新 registration Edge Function。
3. 更新前端，管理員在活動表單可調整「影響大會匯入狀態」。新活動預設不勾選。舊版前端未傳此欄位時保留原設定。

新前端依賴新資料庫欄位，須依序部署。本次未部署遠端環境。

## 驗證

- 隔離本機 PostgreSQL 17 資料庫依序套用至本 migration，初始選中兩筆活動。
- `supabase/testing/verify-conference-import-status.sql` 通過，測試交易回滾：非大會活動回答正常儲存且不觸發、勾選活動回答觸發、未回答補不參加、改回原值不還原、待匯入保持、身分切換、活動改名與勾選切換、成本不觸發；新增活動預設不勾選、可儲存勾選且不觸發；公開頁同樣只有勾選活動回答觸發。`verify-activity-fields-and-permissions.sql` 另驗證 anon 不能呼叫 `conference_choices`。
- `supabase/testing/verify-staff-performance.sql` 通過，涵蓋儲存結果、詳細資料、統計與權限。`verify-hosting-general-only`、`verify-identity-badges`、`verify-independent-identity-prices`、`verify-unified-identity` 也通過。
